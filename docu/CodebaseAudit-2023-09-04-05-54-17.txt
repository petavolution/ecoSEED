## 📊 Project Overview

EcoSEED is an ecosystem simulation game that treats the environment as a "symphony" where different species and environmental factors contribute to harmonic oscillations within dynamic biospheres. The game metaphor views ecosystems not as static systems but as complex oscillatory networks where players act as conductors maintaining balance and resilience.

## 🏗️ Project Architecture

The codebase demonstrates an evolutionary journey, transitioning from a legacy monolithic structure to a modern component-based entity system:

### Legacy Architecture
- Global arrays for entity management (`trees[]`, `birds[]`, etc.)
- Direct object manipulation between entities
- Mixed rendering and logic code
- Animal-specific behavior in separate files
- Monolithic update functions

### New Component-Based Architecture
- Entity-Component-System (ECS) pattern
- Modular components for specific behaviors
- Centralized entity management
- Improved separation of concerns
- Event-based communication

## 📂 Key Directories & Files


### New Architecture Source
- `src/Game.js` - Modern game engine implementation
- `src/core/` - Core engine foundations
- `src/components/` - Reusable modular components
- `src/entities/` - Entity class definitions
- `src/systems/` - Game systems implementations
- `src/behaviors/` - Behavior implementations
- `src/compatibility/` - Legacy code compatibility layer


### Key Component Files
- `src/components/BehaviorComponent.js` - AI state machine (31KB)
- `src/components/SteeringComponent.js` - Movement behaviors (25KB)
- `src/components/CollisionComponent.js` - Collision detection (23KB)
- `src/components/SpriteComponent.js` - Sprite rendering (12KB)



## 🧩 Entity Implementations

### Animal System
The animal implementation showcases the sophistication of the new architecture:

- `src/entities/animals/Animal.js` - Base class with:
  - Component integration (transform, sprite, physics, collision, behavior, steering)
  - Genetics system with procedural generation
  - State machine with eight states (idle, wander, seek, flee, eat, sleep, mate, dead)
  - Needs simulation (hunger, thirst, energy)
  - Perception system for finding food, threats, mates
  - Reproduction system with genetics inheritance

### Plant System
Plants have similar component-based implementations with growth cycles, seasonal effects, and seed generation.

## 🎮 Core Game Mechanics

1. **Oscillatory Ecology Management**
   - Species emit frequency signatures (growth cycles, predator-prey dynamics)
   - Players tune frequencies through species interactions

2. **Keystone Resonance System**
   - Certain species stabilize broader ecosystem harmonics
   - Losing keystones leads to cascading failures

3. **Dynamic Succession & Evolution**
   - Biomes undergo natural cycles: pioneer → developing → climax → disturbance → renewal
   - Evolutionary Potential measured as latent harmonic richness

4. **Temporal Cycles & Shockwaves**
   - Seasons, climate shifts, invasive outbreaks create disturbance pulses
   - Players buffer these pulses through ecosystem resilience

## 🖥️ Technical Implementation

### Rendering System
- Canvas-based rendering with layer management
- Animation system with sprite sheet support
- Camera system with zooming and panning

### Audio System
- Multiple format support (MP3, OGG, WAV) for cross-browser compatibility
- Spatial audio for environment sounds
- Background music with looping

### Input Handling
- Keyboard controls for desktop
- Touch controls for mobile devices
- UI interactions for game controls

### Systems Communication
- Event-based architecture for loose coupling
- Component message passing for related behaviors
- Global event broadcasting for system-wide events

## 📝 Conclusion

The EcoSEED project represents an ambitious ecosystem simulation with a unique harmony-focused metaphor. The ongoing architectural migration demonstrates good software engineering practices, moving from a monolithic design to a component-based architecture while maintaining backward compatibility.

The codebase shows particular strengths in:
- Rich animal behavior simulation
- Complex interactions between different entity types
- Seasonal effects and environmental dynamics
- Procedural generation for entity diversity

The migration to a component-based architecture will provide a solid foundation for future enhancements and make the codebase more maintainable and extensible.
